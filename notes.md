# TryHackMe - Offensive Security Intro

## 1. What is Offensive Security?

Offensive Security is the practice of identifying and exploiting security weaknesses in systems, networks, and applications.

The main goal is to find vulnerabilities before malicious attackers can exploit them.

## 2. Offensive Security vs Defensive Security

### Offensive Security

* Focuses on finding vulnerabilities.
* Simulates attacks on systems.
* Helps organizations identify security weaknesses.

### Defensive Security

* Focuses on protecting systems.
* Detects and responds to attacks.
* Prevents unauthorized access and data loss.

## 3. What is a Vulnerability?

A vulnerability is a weakness or flaw in a system that can potentially be exploited by an attacker.

Examples:

* Weak passwords
* Outdated software
* Improper access controls

## 4. What is an Exploit?

An exploit is a technique or piece of code used to take advantage of a vulnerability.

A vulnerability is the weakness, while an exploit is the method used to take advantage of that weakness.
